[ 사진 넣는 방법 ]

photos/main/     ← 첫 화면에 크게 보일 대표 사진 1장
photos/gallery/  ← 갤러리에 보일 사진들 (여러 장)

- jpg, jpeg, png, webp 파일을 넣으면 됩니다. (아이폰 HEIC 사진은 jpg로 바꿔서 넣어 주세요)
- 갤러리는 파일 이름 순서대로 보입니다. 순서를 정하고 싶으면 01.jpg, 02.jpg ... 처럼 이름을 붙이세요.
- main 폴더에 사진이 여러 장이면 이름순으로 첫 번째 사진만 씁니다.
- 원본 사진을 그대로 넣어도 됩니다. 빌드할 때 휴대폰에 맞는 크기로 자동으로 줄여 줍니다.
- 사진을 넣은 뒤 npm run dev 로 확인하고, npm run deploy 로 배포하세요.
- 폴더가 비어 있으면 해당 부분(대표 사진/갤러리)은 화면에 나오지 않습니다.

[ 카카오톡 미리보기 사진 ]
- 링크를 보낼 때 보이는 미리보기 사진은 photos/main/ 사진을 가로로 잘라(1200×630) 자동으로 만듭니다.
- 얼굴이 잘리는 등 마음에 안 들면, 미리보기용 가로 사진을 photos/kakao/ 에 따로 넣으세요. 그 사진을 우선 씁니다.
